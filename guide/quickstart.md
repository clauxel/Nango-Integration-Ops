# Quickstart

Nango Integration Ops is a SaaS workspace for Nango AI integration ops.

## Fast Path

1. Open Nango Integration Ops and choose a bounded pilot workflow.
2. Enter public-safe examples for Nango AI integration ops.
3. Review the generated queue, evidence, or approval state with the owner.
4. Use pricing and checkout links when the pilot needs a paid workspace.
5. Export the resulting report or evidence for the team record.
